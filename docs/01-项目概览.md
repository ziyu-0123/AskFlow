# 01 · 项目概览

## 1. 项目定位

AskFlow 是一个**全栈的 AI 驱动问卷 / 访谈平台**，本仓库是其中的 **B 端管理端（SPA）**，负责问卷的创建、编辑、发布与统计分析。

整个平台由三个工程组成（本仓库只包含管理端）：

| 工程                          | 技术栈                            | 职责                                            |
| --------------------------- | ------------------------------ | --------------------------------------------- |
| **askflow（本仓库）**            | React 19 + TypeScript + Vite   | 管理端：问卷管理、拖拽编辑器、AI 能力入口、统计分析                   |
| question-server-nestjs（仓库外） | NestJS 12 + MongoDB + Mongoose | 后端 API：用户/JWT、问卷 CRUD、答卷统计、LLM 调用（OpenAI SDK） |
| askflow-client（仓库外）         | Next.js 16（Pages Router）       | C 端填写端：普通问卷表单提交、AI 访谈 SSE 流式对话                |

## 2. 核心功能特性

### 账号与配置

* 注册 / 登录（JWT 鉴权，token 存 localStorage，全局守卫重定向）

* **AI 设置（BYOK）**：用户自带 API Key / Base URL / 模型，服务端只回显打码后的 Key（如 `sk-***abcd`）；内置 DeepSeek / 智谱 GLM / 通义千问 / Kimi 供应商预设

### 问卷管理端

* 问卷列表：关键词搜索（URL 参数驱动）、无限滚动 / 分页、标星、回收站（恢复 + 彻底删除）、复制

* **拖拽式问卷编辑器**：7 种组件、图层管理、隐藏 / 锁定、复制粘贴、撤销重做（20 步）、自动保存（防抖 1s）

* 两种问卷类型：`survey`（普通问卷，走拖拽编辑器）与 `interview`（AI 访谈，走独立提纲配置页）

* 问卷发布与分享（链接 + 二维码）

### 创建端 AI（均依赖用户配置的模型，10\~30s 长耗时请求）

* **自然语言生成问卷**：一句需求 → 结构化问卷（预览后落库）

* **题目 AI 补全 / 润色**：单题优化，原 / 建议对照预览后应用

* **整卷多语言翻译**：英 / 日 / 韩 / 法 / 西 / 俄 6 语言，译文持久化（按 `fe_id` 存文案差异）

* **AI 生成访谈提纲**：根据标题与描述生成引导问题清单

### 分析端 AI

* 单选 / 多选图表（recharts 饼图）+ 答卷表格 + 分页

* **AI 总结开放题**：意见聚类 + 情感分析（正面 / 负面 / 中性）

* **AI 整卷分析报告**：总体结论 + 逐题洞察（含图表建议）+ 改进建议

* 访谈统计：逐份聊天记录（含 token 用量）+ AI 整卷总结

## 4. 关键约束与设计决策

* **BYOK 模式**：AI 能力全部由用户自己的 API Key 驱动，前端只做"未配置引导 + 400 兜底同步标记"。

* **纯生成 / 落库分离**：AI 接口只生成不落库，落库复用问卷更新接口（如译文走独立 `PUT /translations`）。

* **服务端数据归一**：后端返回 MongoDB `_id`，前端在 service 层统一归一为 `id`（见 [09-服务层与API](./09-服务层与API.md)）。

* **撤销范围**：仅组件列表（components）可撤销，页面信息与用户态不参与。

* **AI 长请求**：默认 axios 超时 10s，AI 接口统一放宽到 60s。
