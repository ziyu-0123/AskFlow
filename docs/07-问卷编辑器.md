# 07 · 问卷编辑器（Edit 页面）

目录：[src/pages/question/Edit/](../../src/pages/question/Edit/)。入口组件 [index.tsx](../../src/pages/question/Edit/index.tsx)。

## 1. 整体布局

```
┌────────────────────────────────────────────────────────┐
│ EditHeader（返回 | 标题行内编辑 | 工具栏 | AI翻译/保存/发布）│
├──────────┬──────────────────────────┬──────────────────┤
│ LeftPanel │        EditCanvas        │    RightPanel     │
│ Tabs:    │   （画布：渲染+点选+拖拽） │   Tabs:          │
│ 组件库    │                          │   组件属性         │
│ 图层      │                          │   页面设置         │
└──────────┴──────────────────────────┴──────────────────┘
```

- 进入页面即 `useLoadQuestionData()` 拉取问卷 → `resetComponents` + `resetPageInfo`；
- 画布外层 `onClick` 清空选中（`changeSelectedId('')`），组件自身的点击 `stopPropagation` 后设为选中；
- `useTitle('问卷编辑 - ' + title)` 同步浏览器标签标题。

## 2. EditCanvas（画布）

文件：[EditCanvas.tsx](../../src/pages/question/Edit/EditCanvas.tsx)

- 过滤 `isHidden` 组件后渲染；每个组件包 `SortableItem`（拖拽排序）；
- `genComponent(componentInfo)`：`getComponentConfByType(type)` 查表 → `<Component {...props} />`；
- 选中态/锁定态通过 classNames 切换样式（`.selected` / `.locked`）；
- 拖拽结束 → `dispatch(moveComponent({ oldIndex, newIndex }))`；
- 挂载 `useBindCanvasKeyPress()` 绑定快捷键。

## 3. LeftPanel

[LeftPanel.tsx](../../src/pages/question/Edit/LeftPanel.tsx)：antd Tabs 两个页签。

### ComponentLib（组件库）
[ComponentLib.tsx](../../src/pages/question/Edit/ComponentLib.tsx)
- 遍历 `componentConfGroup` 渲染分组与组件预览（`<Component />` 不传 props，走 defaultProps）；
- 点击预览卡片 → `dispatch(addComponent({ fe_id: nanoid(), title, type, props: defaultProps }))`——插入位置由 `insertNewComponent` 决定（选中项之后）。

### Layers（图层）
[Layers.tsx](../../src/pages/question/Edit/Layers.tsx)
- 全量组件列表（含隐藏项），同样支持 SortableItem 拖拽排序；
- 点击标题：未选中→选中；已选中→进入**行内标题编辑**（Input，`changeComponentTitle`）；
- 隐藏的组件不可选中（message 提示）；
- 每行两个圆按钮：隐藏/显示（`changeComponentHidden`）、锁定/解锁（`toggleComponentLocked`）。

## 4. RightPanel

[RightPanel.tsx](../../src/pages/question/Edit/RightPanel.tsx)：Tabs 联动——有选中组件切到"属性"页，无选中切到"页面设置"页。

### ComponentProp（属性面板）
[ComponentProp.tsx](../../src/pages/question/Edit/ComponentProp.tsx)

- 未选中 → 显示"未选中组件"占位；
- 顶部 **AI 优化按钮**（选中组件被锁定/隐藏时禁用）：
  - 未配置 AI → Modal 引导；
  - 发起 `optimizeComponentService`（**请求函数内部深拷贝 props 快照**，防止生成期间用户切换选中导致快照漂移）；
  - 成功 → `OptimizePreviewModal` 展示原/建议 props 逐字段对比（变化行高亮，选项只比 text）；
  - 应用 → `dispatch(changeComponentProps({ fe_id, newProps, title? }))`——题干变化时同步图层标题，**合并为一次 action 保证一步可撤销**；
  - 失败且 err 含"请先配置" → 同步 `updateAiConfiguredReducer(false)` 并直接打开 AISettingsModal。
- 属性表单 = `getComponentConfByType(type).PropComponent`，注入 `onChange`（dispatch）与 `disabled`。

### PageSetting（页面设置）
[PageSetting.tsx](../../src/pages/question/Edit/PageSetting.tsx)：antd Form 编辑 title/desc/css/js，`onValuesChange` → `dispatch(resetPageInfo(form.getFieldsValue()))`。

## 5. EditHeader（头部）

文件：[EditHeader.tsx](../../src/pages/question/Edit/EditHeader.tsx)，由四个内部组件组成。

### TitleElem（标题行内编辑）
- 受控 Input，`onChange` 直接 `dispatch(changePageTitle(value.trim()))`（始终跟随输入，防止 Redux 旧值覆盖导致"删不掉"）；回车/失焦退出编辑态。

### SaveButton（保存 + 自动保存）★ 重点
```ts
const { run: debouncedSave, flush } = useDebounceFn(() => save(), { wait: 1000 })
useEffect(() => { debouncedSave() }, [componentList, pageInfo])   // 任何编辑→防抖1s自动存
useUnmount(() => { flush() })                                      // 卸载立即冲刷待执行的保存
useKeyPress(['ctrl.s', 'meta.s'], e => { e.preventDefault(); save() })  // 快捷键
```
- 保存载荷：`updateQuestionService(id, { ...pageInfo, componentList })`；
- **卸载 flush** 是关键：防止用户编辑后立即点"返回"时 debounce 被取消导致改动丢失。

### TranslateButton（AI 翻译）
- 未配置 AI → 引导；问卷为空 → 禁用；
- 打开 [AITranslateModal](../../src/pages/question/Edit/AITranslateModal.tsx)：选语言（en/ja/ko/fr/es/ru）→ 60s 翻译 → 原文/译文逐行对照预览（含选项数校验）→ 保存译文 `PUT /api/question/:id/translations`；
- **快照防漂移**：请求发起时 `structuredClone(componentList)` 深拷贝，返回后按"发起时的快照"逐个 fe_id 构建 texts——生成期间用户拖拽/增删组件不会导致译文错位；
- 弹窗打开时会拉一次问卷获取"已翻译语言"并在下拉中标注"将覆盖更新"。

### PublishButton（发布）
- `updateQuestionService(id, { ...pageInfo, componentList, isPublished: true })`；
- 成功 → 跳统计页 `/question/stat/:id`。

## 6. EditToolBar（工具栏）

文件：[EditToolBar.tsx](../../src/pages/question/Edit/EditToolBar.tsx)。未选中组件时整体不渲染。

| 按钮 | Action | 备注 |
| --- | --- | --- |
| 删除 | `removeSelectedComponent` | 自动重算下一个选中 |
| 隐藏/显示 | `changeComponentHidden` | 隐藏时保持选中 |
| 锁定 | `toggleComponentLocked` | 锁定后属性面板禁用 |
| 复制 | `copySelectedComponent` | 深拷贝到暂存区 |
| 粘贴 | `pasteCopiedComponent` | 无暂存时禁用；粘贴换新 fe_id |
| 上移/下移 | `moveComponent` | 首尾禁用 |
| 撤销/重做 | redux-undo `ActionCreators.undo()/redo()` | 历史上限 20 |

## 7. 画布快捷键（useBindCanvasKeyPress）

文件：[hooks/useBindCanvasKeyPress.ts](../../src/hooks/useBindCanvasKeyPress.ts)

| 按键 | 行为 |
| --- | --- |
| Backspace / Delete | 删除选中组件 |
| Ctrl/Cmd + C、V | 复制 / 粘贴 |
| ↑ / ↓ | 选中上 / 下一个组件 |
| Ctrl/Cmd + Z | 撤销（`exactMatch`，避免误触 shift 组合） |
| Ctrl/Cmd + Shift + Z | 重做 |

`isActiveElementValid()` 保证焦点在 body 或 dnd-kit 的 `div[role="button"]` 上才触发，输入框内敲键盘不会误删组件。

## 8. AI 生成问卷（入口在 ManageLayout）

[pages/manage/AIGenerateModal.tsx](../../src/pages/manage/AIGenerateModal.tsx)，三态状态机：

```
idle（输入需求 prompt，≤500字）
  → generating（Spin，10~30s，60s 超时）
      → 成功：preview（标题/描述/组件数/逐条预览，含类型标签）
          → 「创建并编辑」：createQuestionService 建空问卷 → updateQuestionService 写入 AI 内容 → 跳编辑页
          → 「重新生成」：回到 generating
      → 失败：回 idle；"请先配置"则同步标记 + 打开设置
```

生成接口是**纯生成不落库**，落库复用普通创建/更新接口。
