# 06 · 问卷组件体系

核心思想：**每种问卷组件是一个"配置对象"（ComponentConfType）**，同时提供画布渲染、属性编辑、统计图表三种视图，编辑器/统计页通过 `type` 字符串动态查表获取。

协议定义在 [src/components/QuestionComponents/index.ts](../../src/components/QuestionComponents/index.ts)。

## 1. 组件配置协议

```ts
export type ComponentConfType = {
  title: string                                  // 组件显示名（如"单选"）
  type: string                                   // 类型标识（如 'questionRadio'）
  Component: FC<ComponentPropsType>              // 画布/预览视图
  PropComponent: FC<ComponentPropsType>          // 属性编辑表单视图
  defaultProps: ComponentPropsType               // 点击组件库时的初始 props
  StatComponent?: FC<ComponentStatPropsType>     // 统计图表视图（可选，仅选择题有）
}
```

配套导出：

* `componentConfList`：全部 7 种组件配置（查表用）

* `componentConfGroup`：三组分结构（组件库面板渲染用）

* `getComponentConfByType(type)`：按 type 查配置，画布/统计渲染的入口函数

* `ComponentPropsType`：所有组件 props 的**交叉类型**（store 中 component.props 的类型）

## 2. 组件分组

| 分组   | groupId       | 组件                                           |
| ---- | ------------- | -------------------------------------------- |
| 文本显示 | `textGroup`   | QuestionInfo、QuestionTitle、QuestionParagraph |
| 用户输入 | `inputGroup`  | QuestionInput、QuestionTextarea               |
| 用户选择 | `chooseGroup` | QuestionRadio、QuestionCheckbox               |

## 3. 七种组件一览

| type                | 组件   | 关键 props                                               | 默认值要点            | StatComponent |
| ------------------- | ---- | ------------------------------------------------------ | ---------------- | ------------- |
| `questionInfo`      | 问卷信息 | `title`、`desc`                                         | 问卷标题/描述          | 无             |
| `questionTitle`     | 标题   | `text`、`level(1-5)`、`isCenter`                         | "一行标题"、level 1   | 无             |
| `questionParagraph` | 段落   | `text`、`isCenter`                                      | "一行段落"           | 无             |
| `questionInput`     | 单行输入 | `title`、`placeholder`                                  | "请输入..."         | 无（统计页走 AI 总结） |
| `questionTextarea`  | 多行输入 | `title`、`placeholder`                                  | 同上               | 无（同上）         |
| `questionRadio`     | 单选   | `title`、`options: {value,text}[]`、`value`、`isVertical` | 3 个选项            | ✅ 饼图          |
| `questionCheckbox`  | 多选   | `title`、`list: {value,text,checked}[]`、`isVertical`    | 3 个选项（含 checked） | ✅ 饼图          |

所有 props 类型均带可选的 `onChange?: (newProps) => void` 与 `disabled?: boolean`——只在属性编辑场景注入，画布渲染时不传。

## 4. 单个组件的四件套（以 QuestionRadio 为例）

目录 [src/components/QuestionComponents/QuestionRadio/](../../src/components/QuestionComponents/QuestionRadio/)：

### interface.ts — 类型与默认值

```ts
export type QuestionRadioPropsType = {
  title?: string
  isVertical?: boolean
  options?: OptionType[]      // { value, text }
  value?: string              // 默认选中项
  onChange?: (newProps) => void
  disabled?: boolean
}
export const QuestionRadioDefaultProps: QuestionRadioPropsType = { ... }
export type QuestionRadioStatPropsType = { stat: Array<{ name: string; count: number }> }
```

### Component.tsx — 画布视图

* `memo` 包裹；

* **props 解构时合并默认值**：`{ ...QuestionRadioDefaultProps, ...props }`，容忍存量数据缺字段；

* 纯展示（Radio.Group 只读回显 value），不处理用户输入。

### PropComponent.tsx — 属性编辑视图

* antd Form，`onValuesChange` 时 `form.getFieldsValue(true)`（**必须传 true**：Form.List 动态增删时未注册字段会丢失）→ `onChange` 上抛；

* 选项编辑用 `Form.List`：可增删（至少保留 2 项）、校验选项文字不重复；

* 新增选项 value 为空时自动 `nanoid(5)` 补齐（不能原地改，Redux/immer 数据只读，须返回新对象）；

* `disabled`（组件被锁定/隐藏时）透传给 Form。

### StatComponent.tsx — 统计视图

* recharts 饼图（PieChart + ResponsiveContainer），label 显示 `name: 百分比`；

* 颜色取 [constant](../../src/constant/index.ts) 的 `STAT_COLORS`；

* props：`stat: { name, count }[]`（由后端 `GET /api/stat/:qid/:cid` 聚合返回）。

### index.ts — 配置出口

```ts
export default {
  title: '单选', type: 'questionRadio',
  Component, PropComponent, StatComponent,
  defaultProps: QuestionRadioDefaultProps,
}
```

## 5. 各视图的消费方

| 视图              | 消费位置                                                                         | 说明                                                         |
| --------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `Component`     | EditCanvas（画布）、Layers 无、ComponentLib（组件库预览，不传 props）、统计页 ComponentList（左侧预览） | 传 store 里的 props                                           |
| `PropComponent` | ComponentProp（右侧属性面板）                                                        | 注入 `onChange`（dispatch `changeComponentProps`）与 `disabled` |
| `StatComponent` | ChartStat（右侧图表区）                                                             | 传后端聚合的 `stat` 数组                                           |

## 6. 拖拽排序封装（DragSortable）

目录 [src/components/DragSortable/](../../src/components/DragSortable/)，对 dnd-kit 的最小封装，被画布和图层列表共用：

### SortableContainer.tsx

```ts
type PropsType = {
  children: ReactNode
  items: Array<{ id: string; [key: string]: unknown }>   // 需带 id 字段
  onDragEnd: (oldIndex: number, newIndex: number) => void
}
```

* `DndContext` + `SortableContext`（垂直排序策略 `verticalListSortingStrategy`，碰撞检测 `closestCenter`）；

* MouseSensor 设置 8px 拖拽激活距离（区分点击与拖拽）；

* `handleDragEnd` 中按 `fe_id` 找到 old/new index 回调出去（**注意：内部用** **`c.fe_id`** **查找**，因此 items 每项都要有 fe\_id）。

### SortableItem.tsx

`useSortable({ id })` 的标准包装：应用 transform/transition、透传 attributes/listeners。

调用模式（画布与图层一致）：

```tsx
<SortableContainer items={componentList.map(c => ({ ...c, id: c.fe_id }))} onDragEnd={handleDragEnd}>
  {componentList.map(c => (
    <SortableItem key={c.fe_id} id={c.fe_id}>...</SortableItem>
  ))}
</SortableContainer>
```

`onDragEnd` 中 `dispatch(moveComponent({ oldIndex, newIndex }))`（`arrayMove` 重排）。

## 7. 如何新增一种问卷组件（checklist）

1. 在 `QuestionComponents/` 下新建目录，编写四件套：`interface.ts`（Props + DefaultProps）、`Component.tsx`、`PropComponent.tsx`、（选择题类再加 `StatComponent.tsx`）、`index.ts` 导出配置对象。
2. 在 [QuestionComponents/index.ts](../../src/components/QuestionComponents/index.ts)：

   * import 新配置与其 Props 类型；

   * 把 Props 类型加进 `ComponentPropsType` 交叉类型；

   * 加入 `componentConfList` 与合适的 `componentConfGroup` 分组。
3. 若有统计图表，`StatComponent` 的 props 类型也加入 `ComponentStatPropsType`。
4. 涉及 AI 识别的文案字段（翻译/优化）需要同步后端提示词与 [AITranslateModal.tsx](../../src/pages/question/Edit/AITranslateModal.tsx) 的 `buildPreview` switch 分支。
5. 补 `Component.test.tsx` 单测（现有组件均有范例）。
