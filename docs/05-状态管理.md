# 05 · 状态管理（Redux）

Store 定义在 [src/store/index.ts](../../src/store/index.ts)，Redux Toolkit 风格（三个 Slice 组合），组件列表包了 **redux-undo** 提供撤销/重做。

## 1. Store 结构

```ts
export type StateType = {
  user: UserStateType
  components: StateWithHistory<ComponentsStateType>  // redux-undo 包装
  pageInfo: PageInfoType
}
```

```ts
configureStore({
  reducer: {
    user: userReducer,
    components: undoable(componentsReducer, {
      limit: 20,                                   // 最多撤销 20 步
      filter: excludeAction([                      // 这些 action 不产生历史
        'components/resetComponents',
        'components/changeSelectedId',
        'components/selectPrevComponent',
        'components/selectNextComponent',
      ]),
    }),
    pageInfo: pageInfoReducer,
  },
})
```

设计要点：

* **只有 components 参与 undo**：选中态变化、整表重置不污染历史，保证一次 undo 恰好回退一次"结构性/内容性"编辑。

* **列表/统计页数据不进 Redux**：问卷列表、答卷列表等读多写少的数据走 hooks 本地状态，避免全局 store 膨胀。

## 2. componentsSlice（编辑器核心）

文件：[src/store/componentsReducer/index.ts](../../src/store/componentsReducer/index.ts)

### 数据类型

```ts
export type ComponentInfoType = {
  fe_id: string            // 前端生成的唯一 id（nanoid）
  type: string             // 组件类型，如 'questionRadio'
  title: string            // 图层面板显示的标题
  isHidden?: boolean       // 隐藏（画布与 C 端均不渲染）
  isLocked?: boolean       // 锁定（属性面板禁用编辑）
  props: ComponentPropsType  // 组件属性，结构由各问卷组件 interface 定义
}

export type ComponentsStateType = {
  selectedId: string                       // 当前选中组件 fe_id
  componentList: ComponentInfoType[]       // 组件列表（有序）
  copiedComponent: ComponentInfoType | null // 复制暂存区
}
```

### 全部 Action（13 个）

| Action                                        | Payload                       | 说明                                                                       |
| --------------------------------------------- | ----------------------------- | ------------------------------------------------------------------------ |
| `resetComponents`                             | `ComponentsStateType`         | 整表替换（加载问卷数据时），被排除出 undo 历史                                               |
| `changeSelectedId`                            | `string`                      | 设置选中组件（`''` 取消选中），排除出历史                                                  |
| `addComponent`                                | `ComponentInfoType`           | 插入新组件：未选中→尾部；已选中→选中项之后；插入后选中新组件                                          |
| `changeComponentProps`                        | `{ fe_id, newProps, title? }` | **浅合并** props；`title` 可选（题干变化时同步图层标题，合为一次 action 保证单步撤销）                 |
| `removeSelectedComponent`                     | —                             | 删除选中组件，并用 `getNextSelectedId` 计算下一个选中项                                   |
| `changeComponentHidden`                       | `{ fe_id, isHidden }`         | 隐藏/显示；**显示时选中该组件，隐藏时保持当前选中**（否则工具栏按钮无法点回）                                |
| `toggleComponentLocked`                       | `{ fe_id }`                   | 锁定/解锁切换                                                                  |
| `copySelectedComponent`                       | —                             | 深拷贝选中组件到 copiedComponent（`current()` 解包 Immer draft 后 `structuredClone`） |
| `pasteCopiedComponent`                        | —                             | 粘贴：**换新 fe\_id** 后按 addComponent 规则插入                                    |
| `selectPrevComponent` / `selectNextComponent` | —                             | 选中上/下一个组件（快捷键 ↑↓），排除出历史                                                  |
| `changeComponentTitle`                        | `{ fe_id, title }`            | 修改图层面板标题                                                                 |
| `moveComponent`                               | `{ oldIndex, newIndex }`      | dnd-kit 拖拽/工具栏上移下移的排序（`arrayMove`）                                       |

### 工具函数（[utils.ts](../../src/store/componentsReducer/utils.ts)）

```ts
// 删除 fe_id 后应选中的下一个组件：只在「可见」组件中找，删末尾选前一个，否则选后一个
export function getNextSelectedId(fe_id: string, componentList: ComponentInfoType[]): string

// 插入规则：未选中→push 尾部；已选中→splice 到选中项之后；并把 selectedId 切到新组件
export function insertNewComponent(state: ComponentsStateType, newComponent: ComponentInfoType): void
```

### 读取约定（重要）

由于 redux-undo 包装，**读取时必须取** **`state.components.present`**：

```ts
// hooks/useGetComponentInfo.ts
const components = useSelector((state: StateType) => state.components.present)
```

undo/redo 通过 dispatch redux-undo 的 `ActionCreators.undo() / redo()`（见 EditToolBar 与 useBindCanvasKeyPress）。

## 4. userSlice

文件：[src/store/userReducer.ts](../../src/store/userReducer.ts)

```ts
export type UserStateType = {
  username: string
  nickname: string
  aiConfigured: boolean   // 是否已配置 AI（BYOK）——所有 AI 入口的开关
}
```

| Action                      | 说明                                                                  |
| --------------------------- | ------------------------------------------------------------------- |
| `loginReducer`              | 整体替换（登录成功 / 探活成功）                                                   |
| `logoutReducer`             | 重置为初始态（退出登录）                                                        |
| `updateAiConfiguredReducer` | 单独更新 aiConfigured 标记：保存 AI 配置成功置 true；AI 请求返回"请先配置"时置 false（标记过期兜底） |

## 5. 数据进出 Store 的时机

| 时机                  | 动作                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| 进入 Edit/Stat 页      | `useLoadQuestionData` → `resetComponents` + `resetPageInfo`（保留 isHidden/isLocked，防止自动保存把 undefined 写回 DB） |
| 编辑过程                | 各组件 dispatch 对应 action；`SaveButton` 监听 `[componentList, pageInfo]` 防抖 1s 自动 PATCH                         |
| 登录/探活               | `loginReducer`；退出 `logoutReducer`                                                                         |
| AI 配置保存 / AI 400 兜底 | `updateAiConfiguredReducer(true/false)`                                                                   |
