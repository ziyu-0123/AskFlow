## 快速上手

```bash
npm install
npm run dev        # http://localhost:5173（需先启动后端 question-server-nestjs 于 :3005）
```

详见 [11-构建运行与工程化](./11-构建运行与工程化.md)。

## 阅读建议

* **新成员上手**：01 → 02 → 04 → 11，跑起来再回头看模块。

* **改问卷编辑器**：05 → 06 → 07。

* **改 AI 功能**：09 → 08 → 各 AI Modal 源码。

* **加新问卷组件**：06 有完整的"新增组件步骤"。
