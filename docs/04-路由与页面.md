# 04 · 路由与页面

路由定义集中在 [src/router/index.tsx](../../src/router/index.tsx)，使用 react-router-dom v7 的 `createBrowserRouter`。

## 1. 路由表

| 路径                        | 布局             | 页面组件            | 懒加载 | 说明                        |
| ------------------------- | -------------- | --------------- | --- | ------------------------- |
| `/`                       | MainLayout     | `Home`          | ✅   | 产品首页                      |
| `/login`                  | MainLayout     | `Login`         | ✅   | 登录（记住我 → localStorage）    |
| `/register`               | MainLayout     | `Register`      | ✅   | 注册                        |
| `/manage/list`            | ManageLayout   | `List`          | ✅   | 我的问卷（无限滚动）                |
| `/manage/star`            | ManageLayout   | `Star`          | ✅   | 星标问卷（分页）                  |
| `/manage/trash`           | ManageLayout   | `Trash`         | ✅   | 回收站                       |
| `/question/edit/:id`      | QuestionLayout | `Edit`          | ✅   | 拖拽问卷编辑器                   |
| `/question/stat/:id`      | QuestionLayout | `Stat`          | ✅   | 统计页（survey/interview 双形态） |
| `/question/interview/:id` | QuestionLayout | `InterviewEdit` | ✅   | 访谈配置页                     |
| `*`                       | MainLayout     | `NotFound`      | ✅   | 404                       |

结构上有两个顶层分支：

```
/ ─────── MainLayout（eager 加载，作为根 shell）
            └─ manage → ManageLayout → list / star / trash
/question ── QuestionLayout（独立于 MainLayout，无顶栏，占满 100vh）
            └─ edit/:id | stat/:id | interview/:id
```

> 编辑/统计/访谈页是"沉浸式工作区"，刻意不套 MainLayout（无 Logo/用户栏），但同样通过 QuestionLayout 内的 hooks 做鉴权。

## 2. 懒加载机制

```ts
const ManageLayout = lazy(() => import('../layouts/ManageLayout'))
// ...
function withSuspense(Comp: ComponentType): ReactElement {
  return <Suspense fallback={/* 居中 Spin */}><Comp /></Suspense>
}
```

* 每个二级 layout 与页面都是独立 chunk；配合 [vite.config.ts](../../vite.config.ts) 的 `manualChunks` vendor 分包（react/recharts/redux/dnd）。

* MainLayout 保持 eager：所有路由都经过它，懒加载无收益。

## 4. 鉴权流程（Layout 内 hooks 实现）

[MainLayout.tsx](../../src/layouts/MainLayout.tsx) 与 [QuestionLayout.tsx](../../src/layouts/QuestionLayout.tsx) 均执行：

```tsx
const { waitingUserData } = useLoadUserData()   // 探活：无 username 时 GET /api/user/info
useNavPage(waitingUserData)                     // 重定向决策
return waitingUserData ? <Spin/> : <Outlet/>    // 等待期间只渲染 Spin
```

重定向规则（见 [useNavPage.ts](../../src/hooks/useNavPage.ts)）：

| 状态  | 访问页面                          | 结果               |
| --- | ----------------------------- | ---------------- |
| 已登录 | /login、/register              | 跳 `/manage/list` |
| 已登录 | 其他                            | 正常渲染             |
| 未登录 | /、/login、/register            | 正常渲染             |
| 未登录 | 其他（含 /manage/**、/question/**） | 跳 `/login`       |

## 5. 各页面职责

### Home（[pages/Home.tsx](../../src/pages/Home.tsx)）

产品介绍首页，无业务逻辑。

### Login（[pages/Login.tsx](../../src/pages/Login.tsx)）

* antd Form 校验（用户名 5-20 位 `\w+`）；

* 登录成功 → `setToken`（localStorage）→ **立即再拉一次** **`getUserInfoService`** **写 Redux**（防止 useNavPage 因 store 无用户信息弹回登录页）→ 跳 `/manage/list`；

* "记住我"：用户名/密码明文存 localStorage（`USERNAME`/`PASSWORD`）。

### Register（[pages/Register.tsx](../../src/pages/Register.tsx)）

注册成功后自动登录（同样先 setToken 再拉用户信息），跳管理列表。

### ManageLayout（[layouts/ManageLayout.tsx](../../src/layouts/ManageLayout.tsx)）

左侧操作栏是管理端的"功能总入口"：

* **新建问卷** → `createQuestionService()`（type 默认 survey）→ 跳 `/question/edit/:id`

* **新建访谈** → `createQuestionService('interview')` → 跳 `/question/interview/:id`

* **AI 生成问卷** → 未配置 `aiConfigured` 则 Modal 引导；否则打开 `AIGenerateModal`

* 导航按钮：我的问卷 / 星标问卷 / 回收站（按 pathname 高亮）

### List（[pages/manage/List.tsx](../../src/pages/manage/List.tsx)）

无限滚动列表：监听 window scroll（防抖 500ms），容器底边低于视口高度时自动 `load()` 下一页；`keyword` 变化时重置分页状态。数据不进 Redux。

### Star / Trash（[pages/manage/Star.tsx](../../src/pages/manage/Star.tsx) / [Trash.tsx](../../src/pages/manage/Trash.tsx)）

* Star：复用 `useLoadQuestionListData({ isStar: true })` + `QuestionCard` + `ListPage` 分页。

* Trash：antd Table + 行选择；恢复为逐个 `PATCH { isDeleted: false }`（debounceWait 500ms），彻底删除为批量 `DELETE /api/question`（body 传 ids）。

### Edit / Stat / InterviewEdit

分别见 [07-问卷编辑器](./07-问卷编辑器.md)、[08-统计与AI](./08-统计与AI.md)、下文。

## 6. InterviewEdit 访谈配置页

[pages/question/InterviewEdit/index.tsx](../../src/pages/question/InterviewEdit/index.tsx)

访谈型问卷不使用画布编辑器，仅配置三要素：**标题、描述、提纲（outline: string\[]）**。

* 加载：`GET /api/question/:id` → 本地 state（不走 Redux）

* 保存/发布：`PATCH` `{ title, desc, interviewConfig.outline }`（`buildPayload()` 会 trim 并过滤空提纲项；发布额外带 `isPublished: true`，成功后跳统计页）

* **AI 生成提纲**：`generateInterviewOutlineService(title, desc)`，结果整体替换提纲，可继续手动增删改

* 未配置 AI 的引导模式与其它入口一致
