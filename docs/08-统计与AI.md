# 08 · 统计与 AI 能力

目录：[src/pages/question/stat/](../../src/pages/question/stat/)。入口 [index.tsx](../../src/pages/question/stat/index.tsx)。

## 1. 视图分发

Stat 页加载问卷后（`useLoadQuestionData`）按 `pageInfo.type` 分流：

- `type === 'interview'` → 整页渲染 `InterviewStat`（访谈专用视图）
- 否则（survey）→ 三栏视图：`ComponentList | PageStat | ChartStat`
- `isPublished === false` → antd Result 警告"该页面尚未发布"，仅提供返回

选中态提升在 Stat 入口：`selectedComponentId / selectedComponentType` 两个 state 下传三栏联动。

## 2. 普通问卷三栏视图

### ComponentList（左栏）
[ComponentList.tsx](../../src/pages/question/stat/ComponentList.tsx)
- 过滤 `isHidden` 后用各组件的 `Component` 只读渲染（预览）；
- 点击某组件 → 设置 `selectedComponentId/Type` 联动右栏。

### PageStat（中栏）
[PageStat.tsx](../../src/pages/question/stat/PageStat.tsx)
- `GET /api/stat/:qid?page&pageSize` 拉答卷列表（`refreshDeps: [id, page, pageSize]`）；
- 表格列 = 可见组件（列头点击可联动选中；列 dataIndex 为组件 `fe_id`，行数据是 `{fe_id: 答案}`）；
- antd Table + Pagination（默认 `STAT_PAGE_SIZE = 10`）。

### ChartStat（右栏）
[ChartStat.tsx](../../src/pages/question/stat/ChartStat.tsx)——按选中组件类型分流：

| 组件类型 | 渲染 |
| --- | --- |
| `questionInput` / `questionTextarea`（开放题） | `AiSummaryCard`（AI 意见聚类 + 情感分析，替代图表） |
| 单选 / 多选 | 组件配置里的 `StatComponent` 饼图（数据 `GET /api/stat/:qid/:cid` 聚合的 `stat: {name,count}[]`） |
| 其他 | "该组件无统计图表" |

### StatHeader（头部）
[StatHeader.tsx](../../src/pages/question/stat/StatHeader.tsx)
- 分享链接 + 二维码（`qrcode.react` 的 QRCodeCanvas）：`${VITE_CLIENT_BASE}/question/:id`，`useMemo` 缓存（依赖 id、isPublished）；复制用 `document.execCommand('copy')`；
- **AI 解读报告**按钮（未配置引导模式同全局）→ `AIReportModal`；
- 「编辑问卷」跳回编辑页。

## 3. AI 结果组件（与后端响应结构一一对应）

### AiSummaryCard（开放题总结）
[AiSummaryCard.tsx](../../src/pages/question/stat/AiSummaryCard.tsx)

调 `POST /api/ai/summarize-answers { questionId, componentId }`，渲染：

```
summary（总结段落）
意见聚类：themes[] → label + count 条 + 占比横条 + description
情感分布：sentiment{positive,negative,neutral} → 三色堆叠横条（绿/红/灰）
底部：基于 N 条答案 · AI 估算，可能与逐条统计有出入 ｜ 重新总结按钮
```

- 切换组件时清空上次结果（不缓存，保证新鲜）；
- count 为 AI 估算值，占比取整显示。

### AIReportModal（整卷报告）
[AIReportModal.tsx](../../src/pages/question/stat/AIReportModal.tsx)

调 `POST /api/ai/analyze-report { questionId }`，渲染 `ReportResult`：

```
overview     总体结论（左侧蓝色竖线卡片）
insights[]   每题洞察：question + finding + chartDesc（图表建议）
suggestions  改进建议（有序列表）
```

- 关闭即重置（答卷随时在涨，下次打开重新生成）。

## 4. AI 全局交互模式（贯穿所有入口）

所有 AI 按钮共用同一套前置检查与失败兜底（散落在各组件，但模式完全一致）：

```tsx
function handleClick() {
  if (!aiConfigured) {
    Modal.warning({ title: '请先配置 AI 模型', content: '...右上角昵称 → AI 设置...' })
    return
  }
  /* 打开弹窗 / 发请求 */
}
// useRequest.onError：
if (err.message.includes('请先配置')) {
  dispatch(updateAiConfiguredReducer(false))   // Redux 标记已过期
  setSettingsOpen(true)                        // 直接打开设置弹窗
}
```

存在这套兜底的原因：后端可能清除了用户配置（如 Key 无效），而前端 Redux 的 `aiConfigured` 还是 true。

## 5. AISettingsModal（AI 设置，全局唯一配置入口）

文件：[components/AISettingsModal.tsx](../../src/components/AISettingsModal.tsx)。入口：顶栏 UserInfo 下拉「AI 设置」，以及各 AI 弹窗失败兜底。

- **供应商预设**：DeepSeek / 智谱 GLM / 通义千问 / Kimi / 自定义——选中自动填 baseUrl + model；
- 每次打开拉 `GET /api/user/info` 回显（baseUrl/model 直接回显；apiKey 只回显**打码值** `sk-***abcd`，明文不回传）；
- 已配置过时 apiKey 留空表示沿用原值（非必填校验）；baseUrl 强制 `https://` 开头；
- 保存 `PATCH /api/user/ai-config` → 成功 `updateAiConfiguredReducer(true)`。

## 6. InterviewStat（访谈统计）

[InterviewStat.tsx](../../src/pages/question/stat/InterviewStat.tsx)

替代三栏视图的专用页面，两个 Card 纵向排列：

### Card 1：AI 总结访谈
`POST /api/ai/summarize-interview { questionId }`，响应结构与开放题总结相同（`SummarizeAnswersResult`），渲染 summary + 主题聚类（count 为**份数**）+ 情感分布。无答卷时按钮禁用。

### Card 2：访谈答卷列表
`GET /api/stat/:qid/interview?page&pageSize`，每份答卷含：

```ts
{ _id, conversationList: { role: 'interviewer' | 'interviewee', content }[], usage?: { prompt, completion, total } }
```

- antd Collapse 折叠面板：摘要 = 受访者第一条回答（截断 30 字）+ token 用量；
- 展开渲染聊天气泡（interviewer 左、interviewee 右）+ 顶部 token 明细；
- 分页 PAGE_SIZE = 10。

## 7. AI 能力 × 入口 × 接口对照表

| AI 能力 | 入口组件 | 接口（[services/ai.ts](../../src/services/ai.ts)） | 耗时策略 |
| --- | --- | --- | --- |
| 生成问卷 | AIGenerateModal | `POST /api/ai/generate-question` | 60s 超时 |
| 单题优化 | ComponentProp + OptimizePreviewModal | `POST /api/ai/optimize-component` | 60s |
| 整卷翻译 | AITranslateModal | `POST /api/ai/translate-question` | 60s |
| 开放题总结 | AiSummaryCard | `POST /api/ai/summarize-answers` | 60s |
| 整卷报告 | AIReportModal | `POST /api/ai/analyze-report` | 60s |
| 访谈提纲 | InterviewEdit | `POST /api/ai/generate-interview-outline` | 60s |
| 访谈总结 | InterviewStat | `POST /api/ai/summarize-interview` | 60s |

均为**纯生成不落库**；落库分别走 `POST /api/question`、`PATCH /api/question/:id`、`PUT /api/question/:id/translations`。
